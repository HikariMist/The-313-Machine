# Changelog

## 0.1.0 beta polish
- Nights pace to about 10 real minutes; 7 nights per week.
- Three-level upgrades, rebalanced wages and prices, paced jumpscares.
- Animated rain on the title screen, pause menu, in-game feedback screen.
- First-week tips for Nights 1–3 (can be switched off in Settings).
- Customers order more items as the week goes on (1 on Night 1, up to 4 by Night 7, more each cycle and Endless round); each item is paid as it drops, and rule traps still trigger on the first item.
- Eight new walk-in customers on Nights 4–7 (returning regulars: the orange-vest search party, the running club, the girl with the leashes, Officer Brandt). Walk-ins are skipped automatically if a night is already running long.
- Launch price set to $5.99.

## 0.9.0 — first playable (unreleased)
- Seven-night campaign at the Unit 313 vending machine, 52 handcrafted encounters.
- Handbook with sealed and forged pages, security cameras (CAM 0–4), maintenance panel, override keypad.
- 15 endings, each with an achievement; the campaign loops into new cycles that remember earlier ones.
- Endless Mode, unlocked by discovering all 15 endings.
- Six upgrades, inventory and supplier, composure (instability) system, hallucinations, progressive scares.
- 15 original music tracks, 74 sound effects, comfort settings (scare intensity, flashing, shake).
- Dedicated Windows launcher and installer.
