# The-313-Machine
THE 3:13 MACHINE is a psychological horror and supernatural management game developed by Hikari Forge Studios. Survive seven increasingly disturbing night shifts, uncover the truth behind a mysterious vending machine, and discover what happens at 3:13 AM. Built with Unity 6.

## Repository layout
- `Assets/_Project` — Unity project content (scripts, JSON story content, art, audio, fonts)
- `Playtest/` — browser version for playtesting (same game code)
- `Tools/` — tests, compile check, art and audio generators, playtest publish script
- `Art/Source` — approved studio art

See `CLAUDE.md` and `DEVELOPMENT_STATUS.md` for how to build and where things stand.
