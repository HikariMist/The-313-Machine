# Game feature summary (accurate to build 0.9.0)

| Feature | In game |
|---|---|
| Campaign | 7 nights, 52 encounters, phone calls, stockroom investigation (Night 5), final confrontation |
| Endings | 15, each with an achievement; ending screen counts discoveries |
| Replay | Endings start a new cycle; content reacts to cycle count and previous endings |
| Endless Mode | Unlocked by all 15 endings; procedurally assembled rounds, escalating difficulty, best-round record |
| Vending machine | 16 slots + hidden Row E, 18 products, supplier ordering, restocking, receipts, transaction history, motor jams |
| Handbook | Sections A–G, District seal vs forged "REV. 3:13" pages, Mara's handwritten notes |
| Cameras | CAM 1–3 standard, CAM 4 with upgrade, hidden CAM 0 from Night 4 |
| Horror | Horror director with cooldowns, 4 escalation tiers, hallucinations at high instability, scripted jumpscares |
| Upgrades | Expanded Storage, Faster Restocking, Enhanced Monitor, Improved Lighting, Customer ID Tool, Emergency Power Backup |
| Audio | 15 music tracks, 74 effects/ambiences, character motifs |
| Comfort | Scare intensity (3 levels), reduce flashing, reduce shake, volume controls |
| Saves | Automatic at night start/end; backup and corruption recovery; offline |
