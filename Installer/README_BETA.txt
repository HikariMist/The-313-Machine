THE 3:13 MACHINE - CLOSED BETA v0.1.0
Hikari Forge Studios

Thank you for testing! This is an early beta: please expect rough edges.

INSTALL
  Installer: run The313Machine_setup.exe and follow the steps.
             No administrator rights needed. Start from the desktop or Start menu.
  Portable:  unzip The313Machine_Beta_v0.1.0_Windows.zip anywhere and run
             The313MachineLauncher.exe, then press PLAY.
  If Windows SmartScreen appears, click "More info" -> "Run anyway" (the beta is not code-signed yet).

CONTROLS
  Mouse for everything. Space/Enter = next line, H = handbook, M = cameras,
  E = evidence, Esc = pause / close panels.

WHAT'S IN THE BETA
  A full week: 7 nights of about 10 minutes each. 15 different endings;
  finding all 15 unlocks Endless Mode. Upgrades have 3 levels.
  Progress saves automatically at the start and end of every night.

FEEDBACK
  Main menu or pause menu -> "Report a bug / Give feedback" lists the questions we'd love answers to.
  If the game crashed or misbehaved, please attach:
    %USERPROFILE%\AppData\LocalLow\Hikari Forge Studios\The 313 Machine\Player.log
  Saves live in the same folder under \Saves and are kept if you uninstall.

KNOWN ISSUES
  - Some characters, backgrounds and icons still use placeholder art.
  - Campaign length and balance are still being tuned - tell us what felt too easy or too hard.
